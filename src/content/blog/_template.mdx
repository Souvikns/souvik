## Code blocks

Fenced code with `title="..."` metadata renders a titled header with a copy
button. The title is stripped by the `remark-code-meta` plugin.

```ts title="src/example.ts"
export function hello(name: string): string {
  return `Hello, ${name}!`;
}
```
