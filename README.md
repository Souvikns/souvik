# Souvik Portfolio

This repository contains the source code for my personal portfolio website.

## About

This site showcases my projects, blog posts, and background.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS

## Development

Install dependencies and run locally:

```bash
pnpm install
pnpm dev
```
